# Fonts

The two fonts the scripts in [`tools/`](../tools/) load from `fonts/`:

| Font | Author | License |
| :--- | :--- | :--- |
| `BebasNeue-Regular.ttf` | Ryoichi Tsunekawa, Dharma Type | SIL Open Font License 1.1, see [`OFL-BebasNeue.txt`](./OFL-BebasNeue.txt) |
| `PermanentMarker-Regular.ttf` | Font Diner, Inc. | Apache License 2.0, see [`LICENSE-PermanentMarker.txt`](./LICENSE-PermanentMarker.txt) |

These fonts keep their own licenses; the repository's `LICENSE` does not apply to them.

JetBrains Mono, Inter and Liberation Serif are loaded from the system font folders.
